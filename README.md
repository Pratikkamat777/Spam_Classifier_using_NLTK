This project is a Spam Classifier built using Python and Natural Language Processing (NLP). 
It classifies text messages as Spam or Ham (Not Spam) using text preprocessing techniques and machine learning.

Technologies Used:-
 Python
 NLTK (Natural Language Toolkit)
 Pandas
 Scikit-learn
 Google Colab

 Workflow:
 1 Load and explore the dataset.
 2 Preprocess text using NLTK.
 3 Extract features from text data.
 4 Train a machine learning classification model.
 5 Predict whether a message is spam or not spam.

 Objective:
 To identify spam messages using NLP and machine learning techniques.
